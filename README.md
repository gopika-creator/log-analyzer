# Log Analyzer

## Overview

A Python-based cybersecurity tool that analyzes log files and identifies failed login attempts, errors, and frequently occurring IP addresses.

## Features

- Log file analysis
- Failed login detection
- Error detection
- IP address statistics
- Command-line interface

## Technologies Used

- Python 3
- collections.Counter

## How to Run

python main.py
